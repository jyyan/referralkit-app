# ReferralKit

商務引薦小工具 — 用 AI 幫你找共同客群與可互相引薦的產業夥伴。

> 這個 repo 是 ReferralKit 的**公開回饋與 Issue Board**，用來回報問題、提出功能建議與討論。程式原始碼不在這裡。

## ReferralKit 是什麼？

ReferralKit 是給商務引薦團體成員使用的網頁工具，免登入即可使用，提供兩個 AI 工具：

| 工具 | 路徑 | 說明 |
| --- | --- | --- |
| **Power Team Client Finder** | `/power-team` | 輸入多個產業，找出這些產業的共同客群 |
| **Referral Partner Grid** | `/partner-grid` | 輸入一個產業，找出可互相引薦的 8 個產業，以九宮格呈現 |

分析結果可以一鍵複製、存成圖片，或產生分享頁連結傳給夥伴。

## What is ReferralKit?

ReferralKit is a web tool for members of business referral groups. No login is required. It offers two AI tools:

| Tool | Path | Description |
| --- | --- | --- |
| **Power Team Client Finder** | `/power-team` | Enter several industries and find the client groups they share |
| **Referral Partner Grid** | `/partner-grid` | Enter one industry and get 8 industries that can exchange referrals, shown as a 3×3 grid |

Results can be copied, saved as an image, or shared via a share-page link.
